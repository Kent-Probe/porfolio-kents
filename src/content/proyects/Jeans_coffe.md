## Descripción del Proyecto

Jeans Coffee es una plataforma de comercio electrónico desarrollada como proyecto personal que simula un marketplace especializado en productos gastronómicos y café. El sistema ofrece una experiencia de compra intuitiva, similar a plataformas populares de e-commerce, pero adaptada específicamente para el sector alimentario.

## Características Principales

### 🛒 Marketplace de Productos Gastronómicos

- Catálogo de productos de café y alimentos
- Búsqueda y filtrado de productos
- Visualización detallada de productos individuales

### 🍽️ Experiencia de Usuario

- Carrito de compras funcional
- Diseño enfocado en productos alimentarios

### 📱 Funcionalidades Web

- Gestión de productos y inventario
- Sistema de usuarios y autenticación
- Procesamiento de pedidos
- Panel administrativo básico

## Tecnologías Implementadas

El proyecto utiliza un stack web tradicional y eficiente:

- **Backend**: Flask (Python) para la lógica del servidor
- **Base de Datos**: SQLite para almacenamiento local
- **Frontend**: CSS para estilos y diseño responsive
- **Interactividad**: JavaScript mínimo para funcionalidades dinámicas

## Enfoque del Proyecto

Este proyecto personal se caracteriza por:

- Ser una reinterpretación creativa de plataformas e-commerce existentes
- Enfoque específico en el sector gastronómico y de café
- Desarrollo como ejercicio de aprendizaje y portfolio
- Implementación de funcionalidades core de e-commerce

## Arquitectura Técnica

El sistema está construido con:

- Arquitectura MVC ligero utilizando Flask
- Base de datos relacional simple con SQLite
- Templates HTML con Jinja2
- Estilos CSS personalizados para una experiencia visual atractiva

## Aprendizajes y Desarrollo

Este proyecto permitió:

- Explorar el desarrollo web full-stack con Python
- Implementar funcionalidades de e-commerce desde cero
- Practicar diseño de interfaces centradas en productos
- Desarrollar habilidades en gestión de bases de datos relacionales
