## Descripción del Proyecto

El Catálogo de Crédito Samicel es una solución web que facilita a los clientes la consulta de dispositivos móviles disponibles para compra a crédito. Esta plataforma digital permite explorar la oferta de celulares con información completa sobre financiamiento y características técnicas.

## Características Principales

### 📱 Catálogo de Productos

- Visualización clara de modelos de celulares disponibles
- Información detallada de especificaciones técnicas
- Imágenes de alta calidad de cada dispositivo
- Filtros por marca, precio y características

### 💳 Información de Crédito

- Detalles de planes de financiamiento disponibles
- Cálculo automático de cuotas mensuales
- Información sobre entidades financieras asociadas
- Requisitos y condiciones de crédito

### 🎨 Experiencia de Usuario

- Diseño responsivo para todos los dispositivos
- Navegación intuitiva y rápida
- Carga optimizada de contenido
- Interfaz moderna y atractiva

### 📊 Gestión de Contenido

- Sistema de actualización dinámico con Firebase
- Administración sencilla de productos
- Actualización en tiempo real de precios y disponibilidad

## Tecnologías Implementadas

El proyecto utiliza tecnologías modernas para garantizar rendimiento y escalabilidad:

- **Framework**: Astro para generación de sitios estáticos optimizados
- **Base de Datos**: Firebase para almacenamiento y gestión de datos
- **Frontend**: JavaScript vanilla para interactividad
- **Estilos**: CSS moderno para diseño responsivo

## Impacto y Resultados

Esta plataforma ha permitido a Samicel:

- Digitalizar el proceso de consulta de productos a crédito
- Mejorar la experiencia del cliente en la búsqueda de dispositivos
- Facilitar el acceso a información de financiamiento
- Reducir consultas presenciales para información básica

## Arquitectura Técnica

El sistema está construido con:

- Generación estática para máximo rendimiento
- Integración con Firebase para contenido dinámico
- Optimización SEO nativa de Astro
- Despliegue automatizado en Netlify
